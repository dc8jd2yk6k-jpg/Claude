## What changed from v1, and why

v1 (8:50, commit `35b77aa`) got almost no views. Viewers heard the music keep cutting out and the same sound effects over and over. v2 is rebuilt around retention and measured with an automated audio check:

| | v1 | v2 |
|---|---|---|
| Length | 8:50 | 3:49 |
| Hook | 3 s of black, then a slow quote | the −$80.7B slam in the first 2 s, plus an open loop |
| Music dropouts (≥0.5 s, >18 dB below median) | 9 | **0** |
| Abrupt music drops (>15 dB in 0.25 s) | 134 | **0** |
| Ducking | per sentence (pumped) | per passage, −6 dB, slow release |
| Sound effects per minute | 19.1, one identical sample per type | **5.5**, 4 variants per type, never repeated within 30 s |
| Big hits | 5 | 3 |
| Narration | Kokoro `af_heart` at 1.0× | `af_bella` at 1.18× (chosen by audition), timed to the word |
| Packaging | none | thumbnail, 3 titles, chapters, end screen |

`video/tools/audio_qc.py` fails the build if any music gap, pumping, effect repetition or loudness problem comes back.

## How it's made

Everything is generated by code in this repo. There is no stock footage, stock music or video editor.

```
video/
  script/narration.json   the script (display text + text the voice reads)
  tools/kokoro_timed.py   exports a Kokoro-82M variant that also outputs phoneme durations
  tools/tts.py            narration → per-line WAVs + word timestamps → build/timeline.json (+ SRT)
  web/engine.js           deterministic GSAP engine: at(line, phrase) = the spoken word's start time
  web/scenes/*.js         hook, strength, leak, phantom (twist 1), bill (twist 2), verdict + end screen
  render/render.mjs       Playwright + Chromium frame capture → parallel ffmpeg encoders
  render/thumbnail.mjs    1280×720 thumbnail from web/thumbnail.html
  tools/score.py          continuous score: MIDI → FluidSynth (MuseScore General) + numpy synth layers
  tools/sfx.py            budgeted, varied sound design
  tools/mix.py            phrase-level ducking, two-pass loudnorm (−14 LUFS, −1.5 dBTP)
  tools/audio_qc.py       the checks above
  build.sh                runs the whole pipeline end to end
```

### Rebuild

```bash
sudo apt-get install fluidsynth musescore-general-soundfont-lossless ffmpeg
cd video && ./build.sh          # ~40 min on 4 cores; WORKERS=8 to go faster
```
