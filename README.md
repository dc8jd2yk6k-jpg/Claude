# The $80 Billion Paradox

**A motion-graphics explainer (8:50, 1080p30, English narration, original score).**
Why does Anthropic look like the strongest company in AI, while its draft IPO filing shows **$16.3B revenue**, a **$80.7B net loss** in H1 2026, and only **$20.28B** of cash and short-term investments at the end of 2025?

## How it’s made

Everything is generated by code in this repo. There is no stock footage, stock music or video editor.

```
video/
  script/narration.json   the script (display text + phonetic text for TTS)
  tools/tts.py            Kokoro-82M narration → per-line WAVs + build/timeline.json (+ SRT, loudness envelope)
  web/                    the motion-graphics engine (GSAP master timeline, deterministic __seek(t))
    engine.js             timing (word-level cue estimates), camera shake, glitch, grain, light leaks, HUD
    scenes/*.js           one module per chapter
  render/render.mjs       Playwright + Chromium frame capture → 4 parallel ffmpeg encoders
  tools/sfx.py            ~40 synthesized sound effects, placed from cues the scenes emit
  tools/score.py          original score: MIDI → FluidSynth (MuseScore General) + numpy synth layers
  tools/mix.py            VO chain, music ducking under narration, two-pass loudnorm (−14 LUFS, −1.5 dBTP)
  build.sh                runs the whole pipeline end to end
```

- **One timeline drives everything.** The narration is generated first. Its timestamps (`build/timeline.json`) position every animation, every sound effect and every musical hit, so numbers land on the word that says them.
- **Deterministic frames.** Each frame is a pure function of time (seeded RNG, no `requestAnimationFrame`), so workers render frame ranges in parallel and the output is bit-identical between runs.
- **The score** is in D minor at 120 BPM, with chapter starts snapped to two-second bars. Each chapter has its own cue: a ticking cold open, a rising “ascent” built layer by layer across the five exhibits, a heartbeat-and-semitone leak, a pizzicato investigation for the phantom loss, taiko and a Shepard-tone riser for the tower that drops to silence on “25×”, and a piano reprise of the main motif at the end.

### Rebuild

```bash
sudo apt-get install fluidsynth musescore-general-soundfont-lossless ffmpeg
cd video && ./build.sh          # ~45 min on 4 cores; WORKERS=8 to go faster
```

Preview single frames: `node render/render.mjs --stills 58.5,383.5 --outdir build/stills`.

## Sources and caveats

All figures come from **press reports of Anthropic’s draft, unaudited S-1** (Reuters, WSJ, Fortune; Sep 29 – Oct 20, 2026). Supporting sources are Amazon’s 10-Q filings, Anthropic announcements, CNBC/Bloomberg, Axios, Menlo Ventures (an Anthropic investor, disclosed on screen), The Next Web and PitchBook. Every number is footnoted in [`video/script/script.md`](video/script/script.md), along with the places where reports disagree.
